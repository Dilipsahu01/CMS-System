# Business Website

A professional business website built with Next.js and Payload CMS.

## Features

- **CMS-driven content**: All pages are managed via Payload CMS.
- **Modern frontend**: Built with Next.js App Router and Tailwind CSS.
- **SEO optimized**: Integrated SEO plugin for metadata management.
- **Responsive design**: Clean black, white, and grey design system.

## Setup

1. Copy `.env.example` to `.env` and fill in the required variables.
2. Install dependencies: `npm install`
3. Start development server: `npm run dev`
4. Build for production: `npm run build`
5. Start production server: `npm run start`
